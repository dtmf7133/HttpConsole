您好，欢迎使用 Http 控制台！

Http Console 是一个轻量且简单的 Web 控制台，用于管理您的网站。

Http Console 根据 GPLv3 许可证发布，按原样提供，我们对其误用不承担任何责任。

第一步，使用左侧面板密码和盐字段创建要插入配置文件中的哈希值。请记住手动设置盐值。

当您要使用有限的 Web 服务器或 phpfpm 用户在 PHP 进程上下文中运行 Http 控制台时，您必须遵循一些简单的指令以获得最佳的首次设置：
  1. 在您的网络应用路径中创建一个“stage”文件夹；给予阶段文件夹写入权限；并在配置文件中设置阶段路径。
  2. 在阶段路径中创建一个“.HCsampledir”文件夹并授予该文件夹写入权限。此文件夹将是从阶段路径内的新文件夹复制的示例文件夹。
  3. 同样，在阶段路径中创建一个空的“.HCsamplefile”并授予该文件写入权限。该文件将是从阶段路径内的新文件复制的示例文件。
  4. 根据需要配置最大历史记录项和最大召回历史记录项（默认值：50）。

Http 控制台理解一组有限的命令和一组非常有限的参数：
cd、cd..、cp、cp -p、cp -R、帮助、ls、ls -lsa、mv、pwd
