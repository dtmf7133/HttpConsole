Ciao e benvenuto in HTTP Console!

Http Console è una console web leggera e semplice per gestire il tuo sito web.

Http Console è rilasciata sotto licenza GPLv3, viene fornita AS-IS e non ci assumiamo alcuna responsabilità per il suo utilizzo improprio.

Primo passaggio, utilizzare la password del pannello laterale sinistro e i campi salt per creare l'hash da inserire nel file di configurazione. Ricordati di impostare manualmente lì anche il valore del sale.

Poiché eseguirai Http Console nel contesto del processo PHP, utilizzando un server Web limitato o un utente phpfpm, devi seguire alcune semplici direttive per una prima configurazione ottimale:
  1. Crea una cartella "stage" nel percorso della tua app web; dare alla cartella dello stage i permessi di scrittura; e imposta il percorso della fase nel file di configurazione.
  2. Nel percorso dello stage crea una cartella ".HCsampledir" e dai a questa cartella i permessi di scrittura. Questa cartella sarà la cartella di esempio da copiare dalle nuove cartelle all'interno del percorso dello stage.
  3. Allo stesso modo, nel percorso dello stage crea un ".HCsamplefile" vuoto e dai a questo file il permesso di scrittura. Questo file sarà il file di esempio da copiare dai nuovi file all'interno del percorso dello stage.
  4. Configurare gli elementi della cronologia massima e gli elementi della cronologia dei richiami massimi come richiesto (impostazione predefinita: 50).

La console HTTP comprende un insieme limitato di comandi con un insieme di parametri molto limitato:
cd, cd.., cp, cp -p, cp -R, aiuto, ls, ls -lsa, mv, pwd
